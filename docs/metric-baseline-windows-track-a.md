# Metric baseline: Windows, Track A - 2026-08-27T21:23:32-0400

**Track A's counterpart to `docs/metric-baseline-windows.md`**, so
invariant 3's "comparable in design, feature set and performance" has
numbers on this bench too. Regenerate with `python3 tools/metrics.py
--repeats 3 --seconds 3 --out docs/metric-baseline-windows-track-a.md`;
`--out` overwrites, so this block is re-added by hand.

**The playback ladder ran here and did not on macOS**, which confirms
objective 0c does not reproduce on Windows - `docs/metric-baseline-
macos-track-a.md` had to refuse both that and settling.

**Settling still produced nothing, and for a different reason.** The
period search did not converge: `fold_margin` is **1.009** against
Track B's 23.98 on this same bench and host, so the fold is not a
reconstruction and `rise_10_90_ns` reads 0. The report refuses the row
itself. macOS could not have seen this because 0c masked the metric
before it ran.

Chased further, and there are two faults rather than one:

| | Track B | Track A |
|---|---|---|
| ADC sample period | 4.95 us | **5.00 us** |
| phase coverage | 100.0% | **33.3%** |
| fold margin | 24.0x | **1.0x** |
| rise | 12 ticks, AGREES | **0 ticks**, DISAGREES |

`settletime.py` sets `ADC_HZ = 202_000` against `DAC_HZ = 200_000` - a
deliberate 1% offset, so the sample phase walks the waveform. Track B
honours it at 4.95 us. **Track A quantizes the ADC onto exactly 5.00
us, which is the DAC's own update interval at 200 kHz**, so the phase
stops walking and coverage collapses to a third.

That collision is real and it is not the whole fault. Re-run at
`--dac-hz 175000` and coverage returns to **100.0%** with the amplitude
correct at 2743 codes - and the margin is still 1.0x and the rise is
still 0 ticks. (`--dac-hz 190000` lands on a worse collision, 7.7%.) So
giving the fold full phase coverage does not give it a period: the
samples are not phase-coherent with the generator on Track A at all.
Why that is, is a firmware question about Track A's timers and is not
answered here.
