Scope input, divide first

One channel. A 1 megohm input is divided down to fit the 3.3 V ADC, centred on mid-rail, and a 3.3 V op-amp buffers it for the ADC. Values are illustrative starting points, not a design.

Resistor and capacitor values come from hand arithmetic on a 1 MΩ input and a 0.24 attenuation. The contractor's simulation replaces them.
