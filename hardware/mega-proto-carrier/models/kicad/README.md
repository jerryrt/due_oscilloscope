# KiCad 3D models used by this carrier

These nine STEP files are unmodified copies from the KiCad 10 libraries installed at `/Applications/KiCad/KiCad.app/Contents/SharedSupport/3dmodels` when the 3D assignments were added on 2026-10-30. File hashes and original library paths are in [models-3d-evidence.json](../../models-3d-evidence.json).

Source collection: [KiCad kicad-packages3D](https://gitlab.com/kicad/libraries/kicad-packages3D).
Copyright remains with the KiCad library contributors and the authors identified in each STEP header, including KiCAD and kicad StepUp. The switch originates from the KiCad Button_Switch_THT collection and identifies kicad StepUp / ksu MCAD in its STEP header.

Original attribution and license notices in the STEP headers are retained. These copied models are supplied under that library license; the rest of this project keeps its existing licensing.

These are generic visual bodies, not measured vendor parts. Header heights/pin lengths and the straight corner-header body are approximations. The LED model does not establish electrical polarity. Empty grid holes, the empty SMD field and the outer bare digital breakout have no component bodies.
