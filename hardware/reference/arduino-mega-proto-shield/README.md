[schematic](source/proto_shield_MEGA-REV3.sch) are extracted from the
previously retained Arduino reference-design download. The ZIP was removed
at the owner's request; [provenance and hashes](sources.json) remain.

[PDF schematic](../../../docs/datasheets/arduino/arduino-mega-proto-Shield-reference-design.pdf)
remains under `docs/datasheets/arduino/`.

This publisher reference is separate from the owner's photo-reconstructed
[Mega proto carrier](../../mega-proto-carrier/README.md).
